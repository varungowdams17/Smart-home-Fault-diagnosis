PROJECT NOTES

About CircuitSense

A college AI project demonstrating propositional logic through a familiar smart-home scenario.

∴
PROJECT OBJECTIVE

Explainable diagnosis

CircuitSense represents home conditions as propositions and applies a small knowledge base of implications. Its inference trace makes each rule application inspectable rather than displaying a canned answer.

⊨
AI TECHNIQUES

Reasoning methods

  • Forward chaining with modus ponens
  • Backward chaining for literal proof attempts
  • Truth-table model checking for entailment
  • Consistency checks before drawing conclusions
  • Abductive candidate listing for possible causes
!
SAFETY DISCLAIMER

Educational use only

This application is an educational AI fault diagnosis simulator. It does not perform real electrical testing. Electrical faults should be inspected by a qualified electrician.

Never use a simulator output as instructions to touch, test, or repair electrical equipment.
